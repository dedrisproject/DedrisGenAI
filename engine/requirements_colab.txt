# requirements_versions.txt (numpy 1.26.4, safetensors 0.4.3, scipy 1.14.0,

# aborts and installs NOTHING (the engine then dies on `import torchsde`).

#   * torch / torchvision / numpy  -> use Colab's preinstalled, CUDA-matched builds

#                                     falls back to a stand-in when it is missing
#   * pygit2                       -> only used by the legacy auto-updater
#   * rembg / groundingdino / SAM  -> optional (Enhance / auto-mask), installed
#                                     best-effort by the notebook
